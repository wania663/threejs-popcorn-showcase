# Popcorn 3D Landing

An immersive single-file 3D landing page built with Three.js.

## Features
- Curtain reveal intro
- 3D extruded title and striped bucket
- Falling and bursting kernel animation
- Flavour switcher (Classic Butter, Salted Caramel, Peri Peri)
- Bucket size selector and order interaction
- Responsive layout (desktop and mobile)

## Run locally
Open `index.html` in a modern browser. No build step needed.

## Tech
Three.js (r128), vanilla JavaScript, CSS
